## SQRT

**SQRT(x)** - Возвращает квадратный корень от числа *x*.

Запрос 1. [Пример использования функции SQRT](https://github.com/egorbeckish/ArtificialIntelligence/blob/main/SQL+PL-pgSQL/SQL/TypesAndFunctions/1.NumericType/SQRT/sql/query1.sql)
```sql
SELECT
	SQRT(4),
	SQRT(9),
	SQRT(0.04);

--|sqrt|sqrt|sqrt|
--|----|----|----|
--|2   |3   |0,2 |
```
