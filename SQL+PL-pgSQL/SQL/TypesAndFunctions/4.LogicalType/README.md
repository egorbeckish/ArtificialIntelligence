### 4. Логический тип

Переменные и выражения, имеющие логический тип **BOOLEAN**, могут принимать значения **TRUE**, **FALSE** и **UNKNOWN**, которое можно представить значением **NULL**.

Результат логических операций **AND** и **OR** над значениями этого типа приведен в таблицах 6 и 7 соответственно.

**Таблица 6. Таблица истинности логической функции AND с учетом значений NULL**

| AND   | TRUE  | FALSE | NULL  |
|-------|-------|-------|-------|
| TRUE  | TRUE  | FALSE | NULL  |
| FALSE | FALSE | FALSE | FALSE |
| NULL  | NULL  | FALSE | NULL  |

**Таблица 7. Таблица истинности логической функции OR с учетом значений NULL**

| OR    | TRUE  | FALSE | NULL  |
|-------|-------|-------|-------|
| TRUE  | TRUE  | TRUE  | TRUE  |
| FALSE | TRUE  | FALSE | NULL  |
| NULL  | TRUE  | NULL  | NULL  |

---
> В предложении SELECT могут присутствовать выражения, которые имеют логический тип.
