## CURRENT_TIMESTAMP

**CURRENT_TIMESTAMP** - Возвращает текущую дату и время с указанием часового пояса.

Запрос 1. [Пример использования функции CURRENT_TIMESTAMP](https://github.com/egorbeckish/ArtificialIntelligence/blob/main/SQL+PL-pgSQL/SQL/TypesAndFunctions/DateTimeType/CURRENT_TIMESTAMP/sql/query1.sql)
```sql
SELECT
	CURRENT_TIMESTAMP;

--|current_time         |
--|---------------------|
--|20:33:14.019468 +0700|
```
