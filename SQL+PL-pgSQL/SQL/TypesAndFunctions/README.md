Каждый столбец таблицы реляционной базы данных должен содержать данные только одного типа. **Тип данных** определяет значения, которые могут быть присвоены элементам данного столбца, и операции, в которых могут участвовать элементы данного столбца.

PostgreSQL имеет широкий набор встроенных типов данных. Пользователи могут создавать и использовать собственные типы.

Количество типов данных достаточно велико, и в этой главе будут рассмотрены основные встроенные типы, которые далее будут использоваться в примерах. При изучении каждого типа будут приведены основные встроенные функции, аргументы которых могут иметь рассматриваемый тип.

Для вывода результатов выполнения функций и выражений используется оператор **SELECT**. Согласно стандарту, данный оператор должен обязательно содержать предложение **FROM**, но в PostgreSQL данное требование не является обязательным.
